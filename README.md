# airbnb-ml-project

Project Goal

My goal for this project is to explore what factors are related to Airbnb listing prices in Tokyo, and try to predict prices based on the features in the dataset.

Dataset

The dataset is from Inside Airbnb. I'm using the Tokyo dataset from June 30, 2026.

The listings.csv file includes information about Airbnb listings, such as location, room type, number of bedrooms and bathrooms, and price.
